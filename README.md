# 🏋️‍♂️ Fitness Planner System (Workout Plant)

**Live Demo:** [คลิกดูเว็บไซต์จริงที่นี่](https://sutsportworkoutplan.netlify.app/login.html)

Web application สำหรับการจัดตารางออกกำลังกายและบันทึกสถิติรายวัน พัฒนาขึ้นเพื่อช่วยให้ผู้ใช้สามารถวางแผนการฝึกซ้อมได้อย่างเป็นระบบ รองรับทั้งการฝึกแบบ Weight Training และ Calisthenics พร้อมฟีเจอร์ตัวช่วยอำนวยความสะดวกครบครัน

## ✨ Key Features (ฟีเจอร์เด่น)
- **📅 Calendar Dashboard:** ระบบดูตารางฝึกรายเดือนแบบ Interactive
- **⏱️ Rest Timer:** ตัวจับเวลาพักเซ็ตในตัว พร้อมเสียงแจ้งเตือน
- **📄 PDF Export:** สามารถแปลงตารางฝึกและบันทึกออกมาเป็นไฟล์ PDF ได้ทันที
- **☁️ Realtime Cloud Sync:** จัดเก็บข้อมูลผู้ใช้ผ่าน Firebase ปลอดภัยและซิงค์ข้อมูลได้ตลอดเวลา
- **🔄 Data Management:** มีระบบกู้คืนข้อมูล (Import/Export JSON) และระบบล้างข้อมูลตารางฝึก

## 🛠️ Tech Stack (เทคโนโลยีที่ใช้)
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend/Database:** Firebase Realtime Database
- **Libraries:** FontAwesome (Icons), html2pdf.js (PDF Generation)
- **Deployment:** Netlify
